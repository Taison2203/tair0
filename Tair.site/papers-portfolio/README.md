# Портфолио инспектора

Интерактивное портфолио в формате рабочего стола и справочника инспектора. Сайт использует оригинальные пиксельные спрайты и процедурный звук; внешние игровые материалы не включены.

## Запуск

Нужен Node.js 18 или новее. Из каталога `papers-portfolio` запустите:

```powershell
npm start
```

Откройте `http://localhost:3000`. Сайт нужно запускать через HTTP, а не открывать `index.html` как файл: так браузер корректно загружает ES-модули, фото и локальные ресурсы.

## Содержание и фото

Пользовательские данные и видимые тексты находятся в `js/config/content.js`.

- Пустая фамилия, описание проекта или ссылка означает, что данных нет. Интерфейс показывает отметку о засекреченных сведениях и не придумывает факты.
- Проекты, категории навыков, контактные каналы и тексты квитанций редактируются в `CONTENT`.
- Фото кандидата лежит в `assets/img/photo.jpg`. Чтобы заменить его, положите новое изображение по этому пути или измените `CONTENT.passport.photo` на путь внутри сайта.
- Случайные штрихкоды и номера документов используют фиксированные seed, поэтому сохраняют вид при перезагрузке.

## Газетный лист

- Серверный маршрут `/api/news` собирает последние сообщения из RSS-поиска, оставляя публикации с официальных сайтов ВОЗ, Роспотребнадзора и GOV.KZ за последние 30 дней.
- Страница перепроверяет ленту каждые 15 минут; кнопка со стрелкой запускает обновление вручную. Сервер кэширует ответ на 5 минут, чтобы не обращаться к источникам слишком часто.
- В бумажной сводке отдельно помечены даты и источники. Справка по Иркутску — публикация ВОЗ от 10 октября 2026 года, а сообщение о визите Ильхама Алиева — анонс МИД Казахстана на 20–21 октября, не утверждение об итогах визита.
- На статическом хостинге без запуска `server.js` обновляемая лента недоступна; прямые ссылки на официальные публикации останутся открыты.

## Подключение формы связи

По умолчанию форма работает в демо-режиме: она подготавливает черновик, но ничего не отправляет и не утверждает, что сообщение доставлено.

- Для серверного обработчика укажите `contact.endpoint`. Форма отправляет `FormData` методом `POST` с заголовком `Accept: application/json`. Сервер должен ответить статусом 2xx.
- Если серверного обработчика нет, укажите `contact.email`: после подготовки черновика сайт откроет почтовое приложение с заполненными темой и текстом.
- Можно задать `contact.telegram`, чтобы показать ссылку на Telegram и сохранить текст черновика для отправки.

Не храните приватные ключи или секреты в клиентском `content.js`: посетители могут прочитать этот файл.

## Решения

- Все факты о кандидате и проектах собраны в `CONTENT`; интерфейс не добавляет неподтверждённые достижения.
- Без настроенного канала связи форма честно остаётся локальным черновиком.
- Анимации интерфейса используют ступенчатый ритм `steps()`. Для `prefers-reduced-motion` движения и вспышки отключаются.
- Аудио генерируется Web Audio API и подготавливается до начала смены. Музыка не запускается до явного действия пользователя.
- Ссылки на внешние проекты не публикуются, пока владелец не добавит их в `CONTENT.cases`.

## Использованные материалы

- Шрифты загружаются из [Google Fonts](https://fonts.google.com/): Press Start 2P, Pixelify Sans и VT323. Проект использует версии шрифтов, доступные по лицензиям OFL, указанным на страницах семей шрифтов.
- Фото в `assets/img/photo.jpg` предоставлено владельцем портфолио.
- Проект не содержит файлов из папки `assets/ref/`.
